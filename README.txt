TANIE COFFE — 100 MENU DENGAN GAMBAR
====================================

Versi ini berisi tepat 100 menu.

Setiap menu memiliki file gambar JPG lokal sendiri di:
assets/images/

Tampilan menu dibuat dalam sistem slide/pagination:
- 12 menu per slide
- Tombol next/previous
- Search
- Filter kategori
- Sorting
- Favorit
- Keranjang
- Responsive

Cara menjalankan:
1. Extract ZIP.
2. Buka folder tanie-coffee-100.
3. Jalankan index.html.

Semua gambar sudah berada di dalam paket website sehingga tidak perlu memuat gambar menu dari internet.
